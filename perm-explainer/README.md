# perm-explainer

权限卡片弹出时，另外给一个「这条命令会做什么」的提示：作用 / 影响 / 风险。

- **不动系统权限卡片**：原命令、拒绝 / 允许一次 / 始终允许，全都在。
- 只对**高危命令**触发（`rm`、`git push`、`sudo`、`curl | sh`、改注册表、装软件等）。
- 只在实际弹出卡片时提示：命令被自动放行时，插件不提示、不打扰。
- 提示走两条非模态渠道：应用内右上角 toast（12 秒自动消失），加一条系统通知。
- 提示失败或解释生成失败时静默跳过，绝不影响授权本身。

## 安装

```
/plugin install perm-explainer --marketplace AAAYNMMM/claude-plugins
```

## 工作原理（一句话）

`tool.call` 钩子先调用 `next(e)` 但不立刻返回，此时权限卡片弹出并等待；
趁这段时间生成解释，用 `$.ui.toast` 和 `$.ui.notify` 发提示；
如果 `next(e)` 在解释写完前就结束了，说明没弹卡片，直接跳过不提示。

## 调参

都在 `hooks/register.ts` 顶部：

| 常量 | 作用 |
|---|---|
| `RISKY_PATTERNS` | 哪些命令算高危、需要提示；想扩缩范围就改这个数组 |
| `MODEL` / `FALLBACK_MODEL` | 生成解释用的模型，必须是环境允许列表里的完整 id |
| `TIMEOUT_MS` | 单次模型调用的超时，默认 6 秒 |
| `MAX_TOKENS` | 解释长度上限 |
| `TOAST_MS` | 应用内提示停留多久，默认 12 秒 |
| `SYSTEM` | 提示词，想改解释的格式或语气就改这里 |

## 诊断

日志写在插件自己所在的目录：`perm-explainer.log`（仓库已忽略 `*.log`）。
每行记录一次触发：是否高危、调用是否已结束、两种提示是否发出。

## 已知限制

- 桌面版同一时刻只能显示**一个**对话框：调用 `$.ui.ask` 会让系统权限卡片完全不渲染，
  所以提示只能用 toast 和系统通知这类**非模态**形式，不能做成弹窗卡片。
- 系统卡片本身无法被插件写入：`reason` 字段、`$.ui.notice` 都实测无效。
- 若你关闭了系统通知，则只剩应用内 toast 一条渠道。
